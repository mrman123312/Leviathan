# Archive

`source-corpus.md.gz` is a gzip-compressed copy of the full raw Markdown corpus supplied for this Leviathan rewrite. It is retained so the structured research documents can always be traced back to the detailed conversation-derived source material.

To inspect locally:

```bash
gzip -dc archive/source-corpus.md.gz | less
```

The files under `docs/` are the maintained structured synthesis. The archive is intentionally not used as an executable specification.
